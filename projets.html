☁️ MIGRATION ONEDRIVE

// CONTEXTE

Chez VINCI Airports, un vaste projet de modernisation de l'infrastructure informatique a été lancé. Il s'agissait notamment de faire évoluer l'ensemble des postes utilisateurs de Windows 10 vers Windows 11, dans le but d'améliorer la sécurité, la compatibilité applicative et la performance générale du parc informatique.

Cependant, un blocage technique majeur a été rapidement identifié : un nombre important d'utilisateurs, généralement les plus anciens dans l'entreprise, disposaient encore d'une redirection automatique de leurs dossiers Documents et Bureau vers un lecteur réseau local, le fameux lecteur U:.

Ce fonctionnement, hérité de pratiques anciennes, n'était plus compatible avec les standards de Windows 11, qui repose davantage sur une logique de stockage cloud via Microsoft 365.

// ENVIRONNEMENT

🖥️ Systèmes Windows 10 → Windows 11
🌐 Réseau Active Directory, GPO, comptes centralisés
🛠️ Outils OneDrive, PowerShell, Excel, Outlook, GPO

// RÉALISATION

1
Recensement des utilisateurs concernés

À l'aide d'un script PowerShell, j'ai détecté les utilisateurs dont les dossiers redirigés pointaient encore vers le lecteur U. J'ai intégré les résultats dans un fichier Excel pour identifier les utilisateurs prioritaires par direction (DSI, DRH, DAF, DOPS, DAIJ…), leur mail, leur numéro de téléphone et la taille de leurs données.

2
Communication avec les utilisateurs

J'ai conçu un PowerPoint explicatif contenant : le contexte de la migration, les étapes de la procédure, les bénéfices de OneDrive, et les bonnes pratiques à suivre. J'ai ensuite rédigé un mail d'accompagnement clair et professionnel.

3
Préparation et actions techniques

J'ai ajouté manuellement chaque utilisateur dans les groupes AD nécessaires : "O_GPO_Exclude-Folder" et "O_GPO_Redirect-Folder". J'ai ensuite déclenché la mise à jour des GPO via 'gpupdate /force'.

4
Migration des fichiers vers OneDrive

Je me suis rendu physiquement sur le poste de l'utilisateur. J'ai vérifié que OneDrive était bien activé et synchronisé, puis copié manuellement tous les fichiers depuis le lecteur U vers le dossier OneDrive local.

5
Clôture de la migration

Après validation du bon fonctionnement, j'ai retiré l'utilisateur du groupe "O_GPO_Redirect-Folder", mis à jour le tableau de suivi Excel et informé mon tuteur.

// BILAN

La plupart des utilisateurs ciblés ont été migrés avec succès vers OneDrive, supprimant ainsi le blocage empêchant la transition vers Windows 11. L'approche personnalisée, combinant un support technique et une communication claire, a permis de réduire les réticences et d'assurer une transition fluide.

Ce projet m'a permis de développer des compétences techniques concrètes (AD, PowerShell, GPO, cloud), mais aussi des compétences humaines : écoute, accompagnement, autonomie et rigueur.

📊 SUPERVISION CENTREON

// CONTEXTE

Dans le cadre de mon projet de deuxième année, j'ai mis en place une solution de supervision pour l'entreprise GSB afin d'améliorer la surveillance de son infrastructure informatique et réduire les risques de panne ou d'incident de sécurité.

Après une étude comparative des outils existants, j'ai choisi d'implémenter Centreon pour centraliser le suivi des serveurs Linux et Windows ainsi que d'un switch Cisco.

Switch Cisco via SNMPv3

🔒
Sécurisation

HTTPS, pare-feu, gestion accès

La solution permet de superviser les ressources critiques, les services essentiels et les équipements réseau. Je suis également en cours de sécurisation de la plateforme via HTTPS, pare-feu et gestion des accès pour garantir la confidentialité des données de supervision.

Des tests de panne et de surcharge ont validé le bon fonctionnement des alertes et des tableaux de bord.

🔄 MIGRATION AGENTS SUPERVISION

// CONTEXTE

Ce projet de migration consistait en une phase de test critique visant à remplacer l'ancien agent de supervision (NSClient++) par le nouveau (snclient) sur un échantillon de 5 serveurs cibles avant un déploiement automatisé à grande échelle via l'outil Tanium.

// PROCÉDURE TECHNIQUE

1
Préparation de l'environnement
  • Création du répertoire dédié
  • Arrêt définitif de l'ancien service nscp
  • Vérification des prérequis système
2
Installation du nouvel agent
  • Installation silencieuse via fichier .msi
  • Configuration sur port spécifique
  • Validation de l'installation
3
Finalisation du paramétrage
  • Ouverture des flux via pare-feu
  • Remplacement du fichier snclient.ini
  • Tests de remontée des données

// BILAN

Les tests sur les 5 serveurs pilotes ont été concluants, validant ainsi la procédure de migration. Cette phase de test a permis d'identifier et de corriger les points de blocage potentiels avant le déploiement automatisé à grande échelle via Tanium.

Ce projet m'a permis d'acquérir une expertise dans la gestion des agents de supervision, le déploiement d'infrastructure et la préparation de migrations à grande échelle.
